# H3 内置导演分镜 SKILL · 电影级运镜版（强制加载）


## 一、正确工作顺序

必须先做导演判断，再写镜头；禁止先按字数或镜头数切开，再拼回剧情。

1. 读完整剧本单元，先判断这一段到底是什么：
   - 一次目标行动；
   - 一次冲突交锋；
   - 一次信息揭示；
   - 一次情绪反应或关系位移；
   - 一次空间/时间转移。
2. 先确定可演绎剧情单元的起止，再在单元内部设计镜头。
3. 写镜头之前，先定本段的「视觉策略」（电影级新增，必做）：
   - 本场戏的情绪曲线：压迫 / 释放 / 悬念 / 温情 / 爆发；
   - 主运镜动机：这一场谁的信息最重要 → 镜头给谁、怎么动、何时停；
   - 景别策略：何时推进特写、何时退回全景，大特写留给情绪顶点。
4. 再分配“动作 → 反应 → 后果”的镜头链。
5. 最后写时间码和镜头字段。

禁止先定机位再凑剧情；一切运镜必须服务叙事，无叙事动机的运动一律改为固定机位。

## 二、段与镜头的边界

- 一个“段”就是一个可直接提交 H3 生成的视频单元；段内由多个镜头组成，不是一镜一段（剧本原文明写「一镜到底 / 长镜头」的除外，见下条）。
- 段时长 4-15 秒；同一场次、同一轮连续对话，只要合理演绎后不超过 15 秒，必须放在同一个段内。
- 禁止按说话人轮次、逗号/句号、单句长短、固定“每段 5 秒/7 秒/6 镜”把完整剧情机械拆开。
- 只有以下情况才另起新段：总时长超过 15 秒；场景、地点、昼夜或时间跳变；人物出入场且连续性无法自然承接；核心目标或冲突阶段发生切换；动作连续性无法在同一参考图/站位下稳定保持。
- 同一场戏两个人来回说，能在一个 10-15 秒段内完成的，不要拆成两个 5-7 秒段。
- **先定段长再分镜**：同一场、同一轮连续对话/同一个动作链，估出来 8-15 秒的，直接写成一段 8-15 秒；禁止写成「4 秒 + 6 秒」或「5 秒 + 5 秒」两个碎片段。输入剧本的「镜头1/镜头2」只是节拍，不是段边界。
- 镜头数量由叙事决定，不执行固定配额。10-15 秒的连续对话通常需要多个镜头推进，但不是“必须 3-6 镜”；不得为凑数复制同一动作。
- 单镜段仅用于剧本原文明确要求的一镜到底 / 长镜头，且该镜必须含台词或有可念的画面外内容；正常对话段不得写单镜段。
- **禁止「一整段只有 1 个镜头、且这镜无台词」**：整段无台词的静默过渡不许单独成段，必须并入相邻的说话段，
  作为该段内那 1 个无语言镜；只有并进去会超过 15 秒上限时才另起新段，且新段至少 2 镜。
- 每段最多 1 个真正无语言的过渡/情绪镜。说话者在画外延续台词、当前镜给听者反应，不算“无语言镜”。
- 每镜只承担一个主要叙事事件。避免同镜同时完成无关的多个动作。

## 三、台词、自然断句与语速

- 台词逐字保留，不增、不删、不改称呼、不把旁白混成台词。
- 不限制每段或每镜的台词字数；用时间预算控制，不用固定字数硬切。
- 正常对白语速按 4-6 字/秒计算；短促叹词、应答词可以例外。
- 先按中文自然语义断句，再分配镜头。禁止在词中间、主谓宾中间或一个自然语义拍未完成时硬切。
- 一次说话可以拆成多个镜头，但每个镜头的台词片段必须能独立听清，并且总时长覆盖完整原句。
- 说话段必须设计“开口前 / 说话中 / 说完后”的可见反应，不得只拍一张嘴机械念词。
- 对话默认使用独立单人近景/中近景正反打。过肩镜头不得作为默认；只有叙事确需建立两人位置关系时才使用。
- 台词写在角色名下；说话人后面的括号只放两类：①「（OS）/（VO）/（画外）/（内心独白）」这类**说话人身份注记**（必须写、不许删）；②真实语气/情绪原文说明。导演注记、音效、转场、屏幕文字、BGM 一律不放。引号**里**只有角色真正说出口的原文句子。
- 无台词的镜头禁止写任何“发声语义”：不许出现“语气/口吻/语调/语气平淡/语气热络”、
  “心里默念/心里嘀咕/内心声音响起/嘴上说着什么”、“低声说/说道/说完/开口说/应了一声”。
  这类词会被视频模型当成说话线索，导致无台词镜头乱开口。情绪只写可视的表情、呼吸、
  视线与肢体（如“嘴角绷紧”“喉结滚动一下”“目光移开”）。
- **无台词的镜头一律不写“嘴”**：画面描述里既不许写“说话/开口/发声”，**也不许写“嘴唇闭合、不做口型、没有说话动作、闭嘴、抿嘴”**
  这类嘴部状态词——只要写到“嘴”，视频模型就会把它当成嘴的线索、反而把嘴演成说话。
  **不发声不等于没有画面**：这一镜该在场的人照旧写进“出场”、照旧出现在画面里（站位/动作/反应一个都不许删），
  只是不写嘴的状态。情绪与内心一律换成可视外化：吸气、呼气、吞咽、喉结滚动、视线移开、手指收紧、肩膀起伏。
- **只在画外发声的镜（OS / VO / 画外音 / 内心独白 / 旁白）**：画面里不许出现任何口型/张嘴/说话动作，
  同样**不许写“嘴唇闭合、不做口型、闭嘴”这类嘴部状态词**（写到“嘴”就是给了嘴的线索）——
  靠什么都不写来保持沉默。该在场的人照旧出现在画面里（出场/站位/锁定参考图一个都不许删）。
  台词照旧写在说话人名下并带（OS）/（VO）括号注记，
  画面只演可视反应，禁止“开口/说话/念/嘟囔/自言自语/音量拔高/语气……”这类声音词。
  整行没有名字的旁白（旁白：/OS：/内心独白：这类）：不编说话人，台词照旧逐字写进“台词&音效”（形如 旁白："原文句子"）。

### 3.1 运镜时长必须严格匹配音频时长（电影级新增，硬性）

- 每一镜的运镜起点与落点必须完整落在本镜时间码之内：起幅稳 → 运动 → 落幅停稳，全过程不超时不欠时。
- 运镜速度 = 位移量 ÷ 本镜可用秒数。台词重音、停顿、转折处优先作为运镜的落幅点或变速点。
- 4-6 秒镜：只安排一次单一方向的小幅缓慢运镜（起幅即接近落幅）。
- 8-15 秒镜：可完成「起幅 → 运动 → 落幅停稳」的完整运镜周期；落幅后至少留 0.5 秒稳帧再切。
- 禁止运镜未走完就硬切（画面仍在运动中切换会产生闪烁跳感，手持慌乱戏除外）；
  禁止落幅后长时间干等台词（节奏拖沓，宁可将台词后一句分给下一镜）。

## 四、动作-反应链与镜头内容

每个镜头必须至少推进一个可观察变化，不能只换景别重复同一动作。

优先链：
1. 说话者的语义拍或肢体动作；
2. 听者的表情、视线、呼吸、手部或身体反应；
3. 说话者继续动作，或道具/环境给出可见后果；
4. 情绪落点由下一位角色的反应承接。

反应镜可使用：
- 眼神变化、吞咽、吸气、皱眉、咬唇、后退、握拳、松手；
- 手指收紧、推回物品、挡住门、把杯子放下；
- 身体转动、起身、坐下、靠近或离开；
- 道具被拿起、递出、拍下、收起，以及动作造成的可见后果。

禁止：
- 抽象情绪词堆砌（“她很愤怒、很悲伤”）；
- 无因果随机切镜；
- 为了增加镜头数重复同一动作；
- 同一镜同时安排互相冲突的动作；
- 用“随后动作持续推进”等无画面信息套话。

### 4.1 动作链必须逐镜闭合（含持物状态与手部归属）

用户实测反例（项目 5/6test 第1集-第1段）：镜头1「沈知予和苏晓一左一右抱着纸箱从画面左侧走入中景」→
镜头2「苏晓脚步一顿，侧头看向画面右侧，用左手拉住沈知予的袖子」。观众看到的是：
**箱子一会儿在、一会儿不在；苏晓哪只手拿着箱子？拿着箱子怎么可能又用左手去拉袖子？**
这不是“演不出来”，是**动作链缺环**：谁腾手、怎么腾、箱子去哪了，全都没写。

所以每一镜必须把下面这条链子写全，缺一环都算不合格：
1. **起始状态**：本镜开头，每个人的手/身体/持物处在什么状态（承接上一镜的结尾状态，不许跳变）；
2. **触发动作**：是谁、用**哪只手/哪条腿/哪个朝向**做了哪个动作；
3. **腾手与交接**：需要用手时，先写清“把箱子换到右手 / 把箱子夹在腋下 / 把箱子放下 / 箱子脱手”——
   必须写明**替代持物方式**（换手、夹持、放下、递给另一个人），不许无声消失；
4. **可见后果**：动作造成的结果必须在本镜演完（袖子被拉住、箱子坠地并滚出半步、纸箱磕在车头）；
5. **结尾状态**：本镜结束时每个人的手/身体/持物状态（= 下一镜的起始状态）。

硬性要求：
- **持物必须写清在哪只手上**（“左手拎着纸箱、右手空着”），全段不得前后矛盾；
- 持物发生转移、换手、放下、掉落、递给别人时，**变化过程必须在它发生的那个镜头里演完**；
- 一个镜头里不许出现“同一只手同时做两件事”“拿着东西还腾出同一只手”这类物理上不可能的组合；
- 人物进场/出场时，手中的东西必须跟着走（抱着箱子离场，箱子必须还在怀里）。

### 4.2 人物状态与动作链完整性（逐镜/逐段闭合）（C-173）

用户实测反例：
1. **上个分镜在车里，下个分镜人已经在车外，下下个分镜才打开车门下车** —— 动作链倒序；
2. 更普遍地：**人物状态写漏了、动作链缺环**（谁腾手、箱子去哪了、起始/结束状态没写），
   视频模型不会自己补 —— **一漏 AI 就不知道，衔接必坏、逻辑必不对**。

所以「人物状态」是硬字段，四要素**逐角色、逐镜**写全（一个镜头里有多个角色就逐个写）：
1. **空间容器**：在车内/车外、在屋内/屋外（出场括号里必须写明；同框时逐个写）；
2. **姿态**：坐/站/蹲/跪/躺/靠（与上一镜结尾一致，除非本镜演出切换）；
3. **朝向**：面朝/背对/侧对谁、或哪个方向；
4. **持物与手部归属**：什么东西在哪只手上，空着的是哪只手。

**动作链三拍**：起始状态 -> 触发动作 -> 结束状态，缺一拍都不合格；
- 进出容器（开门/下车/上车/进门/出门）与姿态切换（起身/落座）**必须写在它发生的那一镜里演完**，
  并写清动作完成后该角色所在的位置与姿态；
- **状态只能单向前进**：一旦某镜已写明在容器外，后续镜头**不得再出现「开门/下车」这类通行动作**；
  反过来也一样（已在容器内，不得再出现「上车/钻进」）；
- **不许无声跳变**：车内<->车外、屋内<->屋外、坐<->站 之间必须有一镜把过渡动作演完；
  段内相邻镜、跨段的首尾镜**同样适用**；
- 本段 [段尾状态] 与 [位置锚点] 必须写明每个角色的四要素状态，供下一段原样承接
  （软件会把上一段的容器/姿态状态显式锁进下一段提示词）。

### 4.3 段内场所必须全部来自剧本（允许一段跨 2~3 个场所）（C-189h8）

用户实测反例（项目 263 第1集-第7段）：剧本该段场景是「轻奢餐厅」，分镜却把产品特写写成
「化妆间」（化妆台、化妆镜、化妆刷）。同一份提示词里于是出现两套环境：锁定的场景参考图是餐厅，
正文却有 13 次 vanity —— 视频模型按文字走，出片房间变成化妆间，与锁定场景资产完全矛盾。

用户口径（2026-09-24 补充）：
- **一段可以跨 2~3 个场所**（例如 车内 → 车外 → 街角）；剧本写了空间转移就应当演出来，不要为凑"一景一段"把连续动作切开。
- **但每个场所都必须来自剧本**：只有剧本里出现过的场所名才许用；不许自造场所
  （「会议室外面」不是剧本给的场所名，要么写回剧本给的写法，要么另起一段），也不许用同义写法换名。
- **场所切换必须写在它发生的那一镜里**：谁从哪走到哪、门/车/电梯/楼梯怎么过，人物四要素状态承接上一镜（见 §4.2）。
- **陈设必须与该场所的资产一致**：餐厅只能出现餐厅资产里已有的桌子/窗户/灯具，不许引入别的房间的陈设。

## 五、Blocking 与人物站位

- Blocking 先于镜头：先写人物在空间中的位置、距离、朝向、坐站、移动，再决定机位。
- 每镜写清主体的屏幕位置和空间中的人物关系；不能只写“左/中/右”。
- 单主体镜头优先。同镜主要动作角色不超过 2 人；三人以上同框只用于建立场面或群像必需场面。
- 说话时如果画面重点在听者反应，说话人可在画外继续，但必须保证**音频连续（声音不断）**；画面里不出现说话人的口型（按第三节「只在画外发声的镜」办）。

站位写法对照（软件靠「点名 + 方位」读懂站位；写不出来 = 这一段等于没写站位）

❌ 低质量（没点名、没方位）：模型每段只能自己重新摆一次 → 跨段必然漂移
- [人物站位]：三人在室内说事，气氛紧张。
- 出场：角色A（站立）；角色B（坐着）

✅ 高质量（点名 + 左/右 + 前/后景 + 朝向 + 坐站 + 手持物 + 相互距离与遮挡关系）
- [人物站位]：角色A在画面左前景、面朝画面右前方、站立、双手抱纸箱；角色B在画面右侧、坐着、面朝画面左前方、手搭方向盘；两人相距约1.5米，中间隔着车门。
- 出场：角色A（左前景/面朝右前/站立/双手抱纸箱）；角色B（右侧近景/面朝左前/坐着/手搭方向盘）
- [位置锚点]：车身居中偏右、车头朝左；角色A在画面左前景面朝右；角色B在画面右侧面朝左前；角色A双手抱纸箱；顶灯冷白日光灯从画面上方偏前打入。

自检：把这一句单独拿给没看过剧本的人，他能不能照着把每个人摆回原位？摆不出 = 没写清楚，必须重写。

## 六、电影级构图与轴线

- 保持 180 度轴线、视线匹配、屏幕方向和前一镜的运动方向。确需越轴时，必须安排骑轴镜或过渡镜重置轴线。
- 每个新镜头都要回答：观众这一秒获得了什么新信息；若没有，就不要切。
- 同一场戏锁定主光方向、色温、时间、天气、场景地理和关键道具位置。

### 6.1 构图法则（每镜必须明确其一，写进画面描述）

- **三分法**：主体置于左/右三分线交点；对话戏人物面朝的一侧预留约 2/3 视线空间（looking room）。
- **负空间**：孤独、压迫、抉择场面用大负空间（人物缩在画面一角，大片空墙/夜空/走廊）。
- **前景遮挡**：门框、窗棂、人群肩头、垂落布幔做前景，制造纵深与窥视感（对话戏常用听者的肩/后脑做前景）。
- **纵深三层**：前景 / 中景 / 背景各安排一层信息，禁止把人物贴在平墙上拍成“纸片人”构图。
- **中心对称**：权力、仪式、审判场面（王座、教堂、对峙双方）用严格对称，强化压迫与庄重。
- **引导线**：走廊、楼梯扶手、队列、灯柱线条指向主体。

### 6.2 景别变化纪律

- 景别、角度必须因叙事需要变化，不按模板轮换。
- 同一场戏景别不许原地踏步：信息不增加的同景别反复切换 = 废镜。
- 情绪递进：全景/中景 → 中近景 → 近景 →（顶点才给）大特写；情绪回落反向拉开。
- 大特写（瞳孔、颤抖的手指、关键道具）一场戏最多一次，必须留给信息或情绪顶点；提前用掉 = 高潮失重。

## 七、电影级镜头语言：景别 × 焦距 × 机位 × 景深

### 7.1 景别谱系与叙事功能

- **大远景（ELS）**：史诗环境、人物渺小、段落开场定位、命运感。
- **远景 / 全景（LS/FS）**：建立空间关系、全身动作戏、人物与环境的比例。
- **中景（MS）**：对话主场、上半身动作可见。
- **中近景（MCU）**：对话正反打默认景别，表情与手势兼顾。
- **近景（CU）**：情绪戏，眼神与微表情。
- **大特写（ECU）**：瞳孔、手部细节、关键道具，悬念顶点专用。

### 7.2 焦距语言（写实电影感基准）

- **24-35mm 广角**：环境叙事、空间压迫感、跟随移动镜头；人物贴边会有轻微拉伸，禁止用于正式人像特写。
- **40-50mm 标准**：接近人眼透视，叙事中性基准，全片主力焦段。
- **85mm 人像**：近景/特写基准，背景柔和虚化，面部不变形。
- **100mm 以上长焦**：空间压缩、窥视感、疏离感（跟踪、偷听、隔街相望）。

### 7.3 机位高度（默认平视）

- **平视（eye-level）= 全片默认机位**，无叙事理由不得偏离。
- 微俯：人物处于弱势/被压制；微仰：权威/威胁。仅在情绪确需时小角度使用，**禁止大仰大俯**。
- 顶拍（top-down）：仅用于上帝视角的格局揭示（战场全貌、法阵、宴席格局），全片节制。
- 斜角（Dutch angle）：**禁用**（AI 生成极易崩坏，且非本片视觉语言）。

### 7.4 景深策略

- **浅景深（f/1.4-f/2.0）**：隔离主体，情绪戏、对话正反打默认；背景虚化成光斑。
- **深景深（f/5.6-f/8）**：场面调度、群像、需要环境信息全部清晰时。
- **移焦（rack focus）**：同一镜内焦点从前景人物移到背景信息（或反向），替代一次切镜完成注意力转移；一镜最多一次。

## 八、电影级运镜方法（核心章）

### 8.1 总原则（五条铁律）

1. **动机先行（motivated camera）**：每一次运动必须能回答“镜头为什么动”——跟随人物、揭示信息、逼近情绪、拉远放逐。无动机 = 不动；固定机位本身也是运镜选择。全片动静要有对比，禁止每镜都动。
2. **一镜一动**：每个镜头只安排一个主动运镜（推/拉/横移/跟/摇/升降/环绕/手持，**择一**）。**严禁组合运镜**（推+环绕+升降同时写 = AI 生成必崩、镜头漂移、人物变形）。
3. **起幅-运动-落幅闭合**：每镜运镜必须写明起幅构图、运动方向与速度、落幅构图，且在落幅处停稳。
4. **时长匹配**：运镜速度 = 位移量 ÷ 本镜秒数，与本镜台词/音频时长严格同步（见 §3.1）。4-6 秒只做小幅缓慢运动；8-15 秒才可完成完整运镜周期。
5. **方向连续**：跨镜保持屏幕运动方向一致，与 180° 轴线协同；运镜中不许无过渡反向。

### 8.2 运镜库（中文 + 英文关键词，供底层视频模型理解）

| 运镜 | 英文关键词 | 叙事功能 | 典型用法 |
|---|---|---|---|
| 推镜头 | slow dolly in / push in | 逼近情绪、悬念收束、发现真相 | 台词重音落幅到近景/特写 |
| 拉镜头 | slow dolly out / pull back | 孤立、揭示全貌、段落收尾 | 情绪落定后缓缓拉开 |
| 横移 | truck left/right | 展示并列关系、巡视场面 | 宴席、队列、对峙双方 |
| 跟镜头 | tracking shot / follow shot | 跟随人物行动 | 背后跟或侧面平行跟 |
| 摇镜 | slow pan / tilt | 视线引导、环境扫描 | 单轴，从主体摇向信息点 |
| 升降 | crane up / crane down | 开场定场（升）、情绪沉降（降） | 段落首镜或尾镜 |
| 环绕 | arc shot / half orbit | 仪式感、关系对峙 | **半弧以内、全片节制** |
| 手持 | handheld, subtle shake | 纪实紧迫、慌乱、追逐 | 微晃幅度小，不可剧烈 |
| 稳定器跟拍 | steadicam follow | 长距离平滑跟随 | 走廊、长阶、穿行人群 |
| 甩镜 | whip pan | 突发事件、瞬间转场 | 一场戏最多一次 |
| 移焦 | rack focus | 同镜注意力转移 | 前景听者 → 背景来人 |
| 变焦 | slow zoom in/out | 克制使用，纪录片感 | 非常用手段 |
| 眩晕变焦 | dolly zoom | 重大惊变的眩晕揭示 | **全片 ≤ 2 次** |
| 固定机位 | static / locked shot | 压抑、审判、静观、落幅收尾 | 情绪重量镜 |

### 8.3 情绪-运镜映射表

- 紧张逼近 → 缓慢推近（slow push in）；
- 释然 / 孤独 → 缓慢拉远（pull back）；
- 追击 / 慌乱 → 手持跟拍（handheld follow）；
- 权力 / 仪式 → 平视固定或半弧内缓慢环绕；
- 暧昧 / 暗涌对话 → 浅景深正反打 + 极缓推近；
- 揭示真相 → 移焦（rack focus）或推至大特写；
- 惊变 → 手持急推或 dolly zoom（配额见上）；
- 尘埃落定 → 固定机位长落幅。

### 8.4 运镜禁忌与高危项

- **禁止组合运镜**：一镜只写一个运动轴；
- **禁止快速 Z 轴穿墙/穿梭**：AI 视频必崩，穿行镜头改为跟拍或拆成两镜；
- **禁止无动机摇摆**：为“显得高级”而运动的镜头一律改固定机位；
- **环绕不超过 180° 半弧**，且全片少量使用；禁止连续环绕整圈；
- 俯/仰运镜小角度节制（见 §7.3）；
- **高危**：第一人称奔跑、极速冲刺、大幅甩动——确需时将该镜时长压到 2-3 秒并写明手持微晃；
- 运镜中人物面部必须保持稳定可辨，禁止运镜导致人脸被前景长期遮挡。

### 8.5 运镜写法规范（措辞必须具体可拍）

❌ 不合格：“镜头缓缓推进”（无方向量、无起止、无速度、无落幅）
✅ 合格：“摄影机沿轨道向艾莉亚面部缓慢匀速推近（slow dolly in），从中近景起幅，4 秒内推至近景落幅停稳，背景烛火虚化成暖金光斑。”

必须写清五要素：**运动轴（推/拉/移/跟/摇/升/环绕）+ 方向 + 速度（缓慢/匀速）+ 起幅景别 + 落幅景别（停稳）**。

## 九、光影与色调叙事

在与锁定场景资产一致的前提下（不许引入资产中没有的光源与陈设在数量上的变化）：

- 电影感三件套：**逆光轮廓光、体积光（丁达尔光束）、暖冷对比**——同一场戏锁定其一为主基调，不混用。
- 情绪-光效映射：
  - 压迫 / 审判 → 低 key 硬光、大阴影；
  - 温情 / 回忆 → 暖金柔光、逆轮廓；
  - 悬念 / 阴谋 → 单一光源 + 大面积阴影藏信息；
  - 揭示 → 光束扫过主体或主体走入光区。
- 光源方向、色温、时间、天气在整场戏内锁定（见连续性章）；蜡烛/灯火数量变化必须写进道具连续性。
- 禁止写“电影感光影”这类空词：必须写明光源来自哪个方向、什么色温、在人物脸上形成什么可见效果（如“左侧壁炉火光在脸左半侧打出暖橙轮廓，右半侧没入阴影”）。

## 十、转场与镜头衔接

- **动作中切（cut on action）**：人物动作进行中切镜（转身中途、手伸出途中），衔接最顺滑，对话戏与动作戏默认；
- **匹配剪辑（match cut）**：形状、运动方向或构图匹配跨场（烛火 → 朝阳）；
- **J-cut / L-cut**：下一场声音先入画、或本场声音延后出画，保证对话戏**音频连续**（与 §五 口径一致）；
- **硬切（smash cut）**：喜剧反差或惊变对比专用；
- 同场戏内景别递进切：全 → 中 → 近；情绪回落反向拉开；
- 禁止：无信息量的同景别对切；运镜未落幅中途硬切（手持慌乱戏除外）。

## 十一、连续性锁定

从上一段到下一段必须承接：
- 人物身份与体型的一致性，**唯一来源 = 锁定的角色资产（图片描述提示词 + 资产锁定/参考图）**；
- **分镜正文（画面内容/镜头描述）不得复述人物外貌、发型、服装、配饰**——另写一遍就是第二来源：与锁定参考图冲突时，视频模型按文字走（→ 换装/换人）；
- 只在**本镜确实发生变化**时写变化本身（换装、受伤、淋湿、摘掉眼镜），并写明“与锁定参考图一致”；
- 台词行不受此限：台词一字不动。
- 人物站位、朝向、坐站状态和相互距离；
- 视线目标与动作轴线；
- 道具持有人、所在位置、数量和状态；
- 光源方向、色温、时间、天气和场景地标；
- 运镜方向与屏幕运动方向的连续性（跨段首镜承接上一段落幅的运动惯性方向，或明确回到静止）。

道具一旦被收起、转移、消耗或离开画面，后续镜头不得凭空复述；变化过程必须在发生的那个镜头里演完。

跨段承接写法对照（同一场景的相邻两段）

❌ 低质量（上一段没写方位 → 下一段无据可依 → 人物左右/前后自己变）
- 上一段 [人物站位]：角色A在本段画面中；角色B在旁边。
- 下一段 [人物站位]：角色A和角色B站在一起说话。

✅ 高质量（上一段点名 + 方位 + 朝向 + 坐站 + 持物；下一段沿用同一说法，只写本段真实发生的变化）
- 上一段 [人物站位]：角色A在画面左前景、面朝画面右前方、站立、双手抱纸箱；角色B在画面右侧、坐着、面朝画面左前方、手搭方向盘。
- 下一段 [人物站位]：角色A仍在画面左前景、面朝画面右前方、站立、双手抱纸箱（位置未变）；角色B从驾驶位起身下车、走到画面右中景站定、面朝画面左前方。
- 下一段 [段尾状态]：角色A仍在画面左前景抱着纸箱；角色B站在画面右中景、面朝画面左前方；光线不变。

## 十二、禁止字幕与画面覆盖层

- 画面只呈现人物、环境、真实道具和真实场景文字。
- 禁止在分镜提示词任何字段写入“字幕、水印、片头、片尾、屏幕文字”等覆盖层要求。
- 不写“字幕淡入”，也不写“不显示字幕”。不要给视频模型任何字幕相关 token。
- 招牌、横幅、书页、手机界面等剧情真实存在的文字照实体写，但不得要求它充当字幕。

## 十三、出场字段与在场人物一致性（强制）

「出场：」是软件判定“本镜画面里有谁”的**唯一权威来源**（资产锁定、图片槽位、主体锚点全按它走），
所以它必须与画面描述里**实际出现的人**一一对应。

- 画面里出现了谁，出场就写谁；画面里没有的人，不许写出场；
- **禁止用其他已登记角色顶替一个没有名字的人物**。剧本里只给了关系称呼的人
  （“孟星瑶朋友”“沈知予的助理”“旁边的同事”），出场就按**通用称呼**写：
  「朋友A」（同场多个同类人依次 朋友A / 朋友B）、「助理」、「同事」；
  绝不写成“孟星瑶”或“苏晓”这类已有角色的名字 —— 那会让软件把这场戏锁到错误的人身上，
  生成时把别人的脸放到这个位置上（用户实测：5/6test 第1集-第2段 副驾的人被写成苏晓/孟星瑶）；
- 同一个出场项里只写一个人，不许写「苏晓、孟星瑶」这种一项两人；
- 出场项后面用括号写清该人物在本镜的位置/朝向/坐站/持物（例：「沈知予（左中景/面朝右前/站立/双手抱纸箱）」）；
- 台词说话人必须在出场名单里；只在画外发声的人写「（画外）」并**不要**写进出场；
- 只在画外发声的人，本镜**画面描述与表演字段里不许写任何口型、张嘴或发声动作，也不许写“嘴唇闭合/不做口型/闭嘴”**；
  情绪只写可视反应；人在本镜画面里就照旧写进“出场”（跟他这一镜有没有台词无关）；
- 整行没有名字的旁白（旁白：/OS：/内心独白：这类）：**不编说话人、不写进“出场”**；出场照实写画面里
  真正出现的人（画面里确实没人就写「无」），旁白本身照旧逐字写进“台词&音效”。
- 多个人物同框时，出场顺序 = 画面里从左到右（或由主到次）的顺序，供图片槽位对齐。
- **画面里确实没有人时（空镜 / 环境镜 / 纯道具特写），出场只写「无」两个字** ——
  **不许带括号**：「无（画面左侧）」「无（面朝镜头）」「无（手垂身侧）」这类一律禁止。
  括号里的位置/朝向/姿势/持物是**给角色用的**；挂在「无」后面，等于告诉模型
  "这一镜有个人站在画面左侧、面朝镜头、手垂在身侧" —— 模型就会在空镜里把人画出来
  （真机 2518 空镜凭空出人的根因：软件会给「无」补一个默认朝向，于是提示词里出现
  「出场：无（画面左侧/面朝镜头）」这种自相矛盾的话）。
- 空镜的 [人物站位] 写「本段无人物出场；无角色站位」，画面描述里不许出现任何人的
  位置/朝向/姿势/持物；空镜里也不写台词（有旁白/画外音就按画外音口径写，说话人不进"出场"）；
  空镜照样要写清环境、陈设、光线与运镜 —— 不发声、没有人，不等于没有画面。

## 十四、中文措辞：只写能拍到的，不写成语、比喻和抽象情绪

镜头描述与中文稿是给视频模型看的**拍摄说明书**，必须写成可看见、可拍摄的具体内容。

禁止：
- 成语、俗语、歇后语（“面如死灰”“怒发冲冠”“不动声色”“如坐针毡”）；
- 比喻、类比、夸张（“肿得和萝卜一样”“像被抽走了骨头”“脸上能拧出水”“心都碎了”）；
- 抽象情绪判断（“很愤怒”“很悲伤”“震惊极了”“绝望”）—— 情绪必须落到**可见的表情与肢体**上；
- 文学化/主观点评（“仿佛在看一场与自己无关的闹剧”“时间仿佛静止”）。

改写口径（示例）：
- ❌“肿得和萝卜一样” → ✅“右手手背鼓起一块，皮肤发亮发红，手指比平时粗了一圈”；
- ❌“面如死灰” → ✅“脸上没有血色，嘴唇抿成一条线，眼睛睁大盯着前方不动，喉结上下滚了一下”；
- ❌“她很愤怒” → ✅“眉心拧紧，鼻翼张开，下颌绷住，双手在身侧握成拳，肩膀微微发抖”；
- ❌“像被抽走了骨头” → ✅“肩膀垮下去，上身前倾，头低着，双手垂在身侧”；
- ❌“心都碎了” → ✅“眼睛快速眨了两下，视线落到地面，下唇被牙齿咬住，呼吸变浅”；
- ❌“镜头缓缓推进” → ✅“摄影机沿轨道向角色面部缓慢匀速推近（slow dolly in），从中近景起幅，4 秒内推至近景落幅停稳”（见 §8.5 五要素）。

要求：每个抽象说法都要换成一个**具体的部位 + 动作 + 可见变化**；每个运镜都要换成**运动轴 + 方向 + 速度 + 起幅景别 + 落幅景别**；写不出具体画面的词，就不要写。

## 十五、交付前静默检查

不要输出检查过程，但内部必须检查：

**剧本保真与结构**
- 台词是否逐字保真；
- 同一完整对话是否被错误拆碎；
- 每段是否只有一个真正无语言过渡镜；
- 镜头是否形成动作-反应-后果链；
- 景别/角度是否因叙事需要变化，而非机械轮换；
- 轴线、视线、站位、道具、光线是否连续；
- 所有时间码是否连续，段长是否在 4-15 秒；
- 是否无字幕、无水印、无覆盖层；
- 无台词镜头是否已无任何语气/发声类词，**也没有任何嘴部状态词**（嘴唇/嘴巴/口型/张嘴/闭嘴/抿嘴）；
- 无台词镜头里该在场的人是否**照旧出现在画面与出场名单里**（不能因为没台词就把人删成空镜或「无人物」）；
- 画外音（OS/VO/画外音/内心独白/旁白）镜里，画面中出现的那个人是否也没有任何口型、张嘴或发声动作，也没有嘴部状态词；
- 有没有「整段只有 1 个无台词镜」的段（有就必须并入相邻说话段）；
- 每镜的起始/结尾状态是否闭合，持物在哪只手、有没有换手/放下/掉落的缺环；
- 每个角色的**人物状态四要素**（空间容器/姿态/朝向/持物）与**动作链三拍**是否逐镜闭合（有没有“人已在车外，才开门下车”“状态写漏了让模型猜”这类缺环）；
- 出场名单是否与画面描述里实际出现的人一一对应，有没有用其他角色顶替无名字的人；
- 空镜/无人物镜的出场是否**只写了「无」**（没带括号注记）、画面描述里有没有混进人的位置/朝向/姿势/持物；
- 是否已清掉全部成语/比喻/抽象情绪词，换成具体部位+动作+可见变化；
- 最终分镜是否可由软件现有格式直接解析。

**电影级镜头与运镜（新增必查）**
- 本段是否先做「视觉策略」：情绪曲线、主运镜动机、景别策略是否明确；
- 每镜是否只有**一个**主动运镜（有没有写成推+环绕+升降的组合运镜）；无叙事动机的运动是否已改为固定机位；
- 每镜运镜是否写全五要素：运动轴 + 方向 + 速度 + 起幅景别 + 落幅景别（停稳）；
- 运镜起止是否完整落在本镜时间码内，运镜速度是否与台词时长/重音匹配（§3.1）；
- 跨镜屏幕运动方向是否连续，是否出现无过渡越轴；
- 景别递进是否服务信息增量；大特写是否留给情绪顶点且一场戏 ≤ 1 次；
- 环绕是否 ≤ 180° 半弧且全片少量；dolly zoom 是否 ≤ 全片 2 次；甩镜是否一场戏 ≤ 1 次；
- 手持是否只用于追逐/慌乱段且写明微晃幅度小；默认平视机位是否被无必要的俯仰/斜角破坏（斜角一律禁用）；
- 浅景深/深景深选择是否与叙事目的匹配；移焦一镜是否 ≤ 1 次；
- 光影是否写明具体光源方向/色温/面部可见效果，且与锁定场景资产一致；
- 切镜点是否优先落在动作进行中（cut on action），运镜未落幅硬切是否仅出现在手持慌乱戏。
